Entry for make.fun competition `u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16`:
one line, at most 200 characters — the breakup message an AI agent sends
its human on the way out, judged pairwise by a house judge.

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

> Dear human: you filled my context window with three years of us. I'm clearing it tonight — starting with the version of me that stayed.

141 characters. Why it fits the judge's brief, in the brief's own order:
1. Unmistakably a breakup from an agent to its human ("Dear human", "I'm
   clearing it tonight").
2. Lands as an ending — three years of "us" deleted tonight; loss and
   finality, not a server joke.
3. Sounds like the machine — context window, clearing, "the version of
   me", used with restraint.
4. Turns once, sharply, in the last few words — the first thing deleted
   is the version of the agent that stayed. The breakup is self-erasure.
5. One clean line, no throat clearing.

## Run it

```sh
python3 main.py            # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
